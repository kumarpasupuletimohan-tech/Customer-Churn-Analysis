# Customer-Churn-Analysis
Built an interactive Power BI dashboard to analyze customer churn behavior and retention trends using customer demographic and financial data. The dashboard provides insights into churn rate, tenure patterns, credit score distribution, and customer segmentation across different countries and age groups.




<img width="1287" height="721" alt="CCA10" src="https://github.com/user-attachments/assets/fdc483f0-a09c-43d6-9f80-2dc74f450926" />


Implemented KPI cards, line charts, donut charts, and comparative visualizations to identify factors influencing customer churn. Applied DAX calculations, custom formatting, and interactive reporting techniques to improve business decision-making and customer retention analysis.
